# 四段式监控日报模板

每个交易日收盘后（或工作日早间定时任务）输出一份日报，结构固定为四段。参考 GitHub `daily_stock_analysis` 的段落风格。

---

## 模板

```markdown
# 基金监控日报 · YYYY-MM-DD

## 【核心结论】
一句话：今日最该买 / 最该卖 + 总档位。
例：三宽基综合信号均 1.38，按档位执行；标的C 触发规则1a，今日最该卖（减 1/3）。

## 【数据面】
日期 + 交易日说明；每个标的一行，PE 分位双口径并列：

| 基金 | 净值/涨跌 | vs成本 | PE分位(蛋卷10年) | PE分位(iFinD近1年) | RSI6(口径) | 综合倍数 | 档位 | 建议占比% |
|---|---|---|---|---|---|---|---|---|
| ... | ... | ... | ... | ... | ... | ... | 多补/少补/不补 | ... |

（附：数据来源与日期；缺数如实标注"暂无数据"。档位可用估值×RSI矩阵快速判读。）

## 【情报面】
- 🎯 长期仓定投开关：给开/关 + 一句理由
- 💰 三重止盈监控：每只基金距三条止盈线的距离
  （估值线 / 回撤线 / 移动线；来自 exit-check 的 take_profit_lines）
- 📢 公告监控：近 3 天公告（查询需带基金名+状态词）
- 📰 市场事件：影响执行的热点，一句话+依据
- 🌡️ 社区情绪温度计：贪婪/中性/恐慌档（见 [community-analysis.md](community-analysis.md)）

## 【作战计划】
1. 信号≥1.0 的标的 → 档位与占比（不给金额）
2. 现价低于成本的标的 → 补仓档（× 日均额倍数）
3. 触发止盈的标的 → 规则编号 + 动作（减1/3、卖一半…）
4. 弹药进度 → 剩余预算占比提示（不含金额明细）
```

## 示例（虚构数据，仅演示格式）

```markdown
# 基金监控日报 · 2026-10-16

## 一、核心结论
标的A 信号 1.38（估值1.0×均线1.2×RSI1.15），可执行档位买入；
标的B RSI6=81 超买，今日不追；标的C 触发规则1a，建议减仓 1/3。

## 【数据面】
2026-10-16，交易日。

| 基金 | 净值/涨跌 | vs成本 | PE分位(蛋卷10年) | PE分位(iFinD近1年) | RSI6 | 综合倍数 | 档位 | 建议占比% |
|---|---|---|---|---|---|---|---|---|
| 标的A | 1.1138 / -0.9% | -10.5% | 22%（暂无数据则标） | 34.8% | 8.7 | 1.38 | 多补 | 25% |
| 标的B | 1.6729 / +0.4% | +3.2% | 暂无数据 | 61.2% | 81（RSI6） | 0.5 | 不补 | 15% |
| 标的C | 1.7065 / +0.6% | +2.8% | 暂无数据 | 87.0% | 55 | — | — | 止盈 |

来源：iFinD 收盘 + 蛋卷估值（YYYY-MM-DD）。

## 【情报面】
- 🎯 长期仓定投开关：开——标的A 处于低估区间，符合长期定投条件
- 💰 止盈监控：标的C 估值线距离 -2.0（已越过 85% 线）；标的A 回撤线距离 8（未激活，浮盈<10%）；标的B 移动线距离 5（正常）
- 📢 公告监控：近 3 天无异常公告（按"基金名+限购/暂停申购/分红"检索）
- 📰 市场事件：无影响执行的事件
- 🌡️ 社区情绪温度计：贪婪档（晒盈帖占优、"求上车"帖增多）→ 对照估值档收紧执行

## 【作战计划】
1. 标的A：信号 1.38 ≥ 1.0 → 按弹药占比执行
2. 标的A 现价低于成本约 10.5% → 补仓档 12.5× 日均额
3. 标的C：规则1a 减仓 1/3
4. 本月剩余弹药约 XX%，注意分批
```

## 写作纪律

1. **只出现档位与占比**：金额一律用"× 日均额"表达，禁止替用户算具体金额
2. **每个数字有出处**：来源+日期，没有就写"暂无数据"
3. **双口径并列**：PE 分位蛋卷 10 年与 iFinD 近 1 年两列都给，信号计算只用近 52 周口径
4. **口径标注**：RSI 输出必须标注口径（RSI6/RSI14）
5. **结论先行**：核心结论一句话，让用户 10 秒读完
