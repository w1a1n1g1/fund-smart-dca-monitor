# 四段式监控日报模板

每个交易日收盘后（或工作日早间定时任务）输出一份日报，结构固定为四段。

---

## 模板

```markdown
# 基金监控日报 · YYYY-MM-DD

## 一、核心结论
（3 行以内：今天买不买、买什么档位、止盈有没有触发。
例：三宽基综合信号均 1.38，可按档位执行；红利超买不追；黄金敞口偏重不加。）

## 二、数据面
| 指数 | 收盘 | 涨跌 | PE分位(52周) | 价/MA250 | RSI6 | 综合信号 |
|---|---|---|---|---|---|---|
| ... | ... | ... | ... | ... | ... | ... |

（附：数据来源与日期，缺数如实标注"暂无数据"）

## 三、情报面
（1-4 条：超买/超重/暂停申赎/假期顺延等风险提示，每条一句话+依据）

## 四、作战计划
1. 信号≥1.0 的标的 → 给档位与占比（不给金额）
2. 现价低于成本的标的 → 补仓档（× 日均额倍数）
3. 触发止盈的标的 → 规则编号 + 动作（减1/3、卖一半…）
4. 弹药进度 → 剩余预算占比提示（不含金额明细）
```

## 示例（虚构数据，仅演示格式）

```markdown
# 基金监控日报 · 2026-10-16

## 一、核心结论
标的A 信号 1.38（估值1.0×均线1.2×RSI1.15），可执行档位买入；
标的B RSI6=81 超买，今日不追；标的C 触发规则1a，建议减仓 1/3。

## 二、数据面
| 指数 | 收盘 | 涨跌 | PE分位(52周) | 价/MA250 | RSI6 | 综合信号 |
|---|---|---|---|---|---|---|
| 指数A | 5000.00 | -1.50% | 34.8% | 0.88 | 8.7 | 1.38 |
| 指数B | 4200.00 | -1.20% | 35.8% | 0.90 | 9.7 | 1.38 |

来源：iFinD，YYYY-MM-DD 收盘（示例）。

## 三、情报面
- 指数B 的 RSI6 高位超买（81），纪律上当日不追
- 标的C PE 分位 87% > 85%，触发规则1a

## 四、作战计划
1. 标的A：按弹药占比执行（A 55% / B 20% / C 10% / 机动 15%）
2. 标的A 现价低于成本约 10.5% → 补仓档 12.5× 日均额
3. 标的C：规则1a 减仓 1/3
4. 本月剩余弹药约 XX%，注意分批
```

## 写作纪律

1. **只出现档位与占比**：金额一律用"× 日均额"表达，禁止替用户算具体金额
2. **每个数字有出处**：来源+日期，没有就写"暂无数据"
3. **结论先行**：核心结论不超过 3 行，让用户 10 秒读完
4. **不复述隐私**：不罗列用户持仓明细与成本，除非用户当轮主动提供
