# 盘友圈公开实盘分析框架

> 用途：把支付宝盘友圈里**公开的实盘帖**（晒操作、晒成本、晒收益）变成结构化的纪律对照分析。
> 铁律延续：只做诊断与参考，**不跟单、不给金额、不代操作**。

## 0. 合规边界（先读）

1. **为什么不自动抓取**：支付宝无公开 API，盘友圈内容依赖登录态且位于 App 容器内；自动抓取涉及平台条款与账号风控风险，本项目不提供、不建议。采用**人贴内容 + AI 分析**的半自动模式。
2. **只分析公开内容**：仅处理用户主动粘贴/截图的公开帖子；不存储、不复述他人头像、昵称等可识别信息（分析输出中一律称"发帖人"）。
3. **不构成跟单建议**：诊断结论是"该操作与三因子纪律的对照结果"，不是对该发帖人的能力评价，更不是买入推荐。

## 1. 输入与要素提取

用户粘贴文字或截图后，按下方字段表提取（缺项如实标"未披露"，不臆测）：

| 字段 | 说明 | 缺失时处理 |
|---|---|---|
| 标的 | 基金名称/代码，或其跟踪指数 | 无法定位指数则终止并说明 |
| 成本 | 发帖人披露的持仓成本 | 无法算浮盈，只做信号对照 |
| 操作 | 买入 / 卖出 / 持仓观望（含金额可选） | 必填，无法判断则追问 |
| 仓位占比 | 发帖人披露的该标的占比（可选） | 缺失则跳过集中度分析 |
| 发帖情绪 | 晒单语气：兴奋/焦虑/平静 | 记录，供情绪温度计汇总 |

## 2. 分析流程（五步）

1. **提取要素**（上表）
2. **取数**：按 [data-sources.md](data-sources.md) 优先级取该标的**跟踪指数**的 PE 分位、现价、MA250、RSI6
3. **算信号**：`python scripts/fund_strategy.py signal ...` 得到当前三因子信号
4. **一致性诊断**：`python scripts/fund_strategy.py peer-check --action buy --cost <发帖人成本> --price <现价> --pe-percentile <..> --ma250 <..> --rsi6 <..>` 输出诊断卡
5. **输出诊断卡**（模板见下），附情绪温度计与借鉴点

## 3. 诊断卡模板（虚构示例）

```
📋 盘友圈实盘诊断（发帖人，2026-XX-XX）
标的：某沪深300指数基金（跟踪指数：沪深300）
发帖操作：买入 ｜ 披露成本 1.02 ｜ 现价 1.09（浮盈 +6.9%）
当前信号：1.0 × 0.9 × 1.15 = 1.04（≥1.0，纪律区间）
诊断：✅ 与纪律信号一致——年线上方不远+超卖修复段顺势买入
风险标记：⚠️ 无
可借鉴点：成本控制（低位分批建仓）；其仓位占比未披露，集中度未知
——仅为纪律对照，不构成跟单建议
```

## 4. 情绪温度计（社区逆向参考）

每日/每次刷盘友圈时，按三个观察维度打分，汇总成三档：

| 维度 | 贪婪信号 | 恐慌信号 |
|---|---|---|
| 晒单盈亏比 | 晒盈利帖明显多于亏损帖 | 集中晒浮亏/割肉 |
| 追热倾向 | "求上车""还能追吗"类提问扎堆 | "要不要清仓""扛不住"类提问扎堆 |
| 新手浓度 | 萌新晒收益、晒加仓 | 萌新问"怎么办" |

- **贪婪档**：逆向提醒——对照 PE 分位，若估值档已 ≤0.5，收紧执行（只看不动）
- **恐慌档**：逆向提醒——对照 PE 分位与 RSI，若信号 ≥1.0，恰是纪律档位该执行的时点
- **中性档**：一切按信号表机械执行

> 情绪温度计只做**纪律执行的辅助提醒**，永远不单独触发操作。

## 5. 红线清单

- 不复述他人昵称/头像/主页链接等可识别信息
- 不给任何"跟单/抄作业"结论，一律落到"对照纪律后你自己决定"
- 输出中不出现用户自己的持仓明细（隐私隔离，同 [data-sources.md](data-sources.md) 第 4 条）
- 他人晒单样本存在**幸存者偏差**：晒盈不晒亏是常态，风险标记必须写明
